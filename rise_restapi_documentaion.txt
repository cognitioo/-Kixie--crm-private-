👋 Introduction
The RISE API operates over HTTPS and uses JSON as its data format. The API is a RESTful API and utilizes HTTP methods and HTTP status codes to specify requests and responses. A token is bound to a whole RISE installation. To interact with the API of another RISE's installation, you have to create a new token inside this installation.

‍💻Getting started
To get started using the API you first need an API token, after activating our plugin.

As long as you download our API plugin from CodeCanyon, extract its contens. File upload.zip contains the plugin files (in a plugin format) that you upload in RISE CRM's Plugins installation section.

✏️ ️API activation
Step 1) Navigate to Settings -> Plugins -> Install plugin (upper right area).

Step 2) Drag n drop the downloaded file from envato and enter your license key. Press install and the plugin should be installed.

Step 3) Close the screen and select the actions in the right area of the activated API plugin, then select Activate from the dropdown actions list.

Step 4) Once the plugin is activated successfuly, a new menu will appear in your admin area's dashboard, called API Management. This is the management area for the API users. You will need to browse there and created API tokens/users for authenticated use.

Step 5) Create your first user and copy the necessary token - it will need to be used in every API command.

⛓️ Usage of the API
Available commands of the API are described below, along with their request-response examples for every endpoint.
We are using authtoken header value for authentication and multipart-form type for data operations (POST/PUT).


Keep in mind that if your installation contains an /index.php/ routed URL, you will need to include this in your API Postman commands.
Trailing slash is usually ignored or eliminated by most of webservers, but in case you receive a Route not found error at the command sent, you can safely ignore including it.



If you are not familiar with REST APIs, we strongly suggest that you hire a professional, in order to have your third party connections done.
Familiarization with REST APIs is a prerequisite for this item and getting you into its learning falls outside the scope of the support of this item.
📇 Sample usage (example command)
Scenario: Your token is jEheVytlAoFl7F8MqUQ7jAo2hOXAS and that you need to list all available customers of your Perfex's installation, through a cURL request.


Use Case: You will need to execute the following terminal command:

curl -H "authtoken: jEheVytlAoFl7F8MqUQ7jAo2hOXAS" https://yourdomain.com/index.php/api/tickets
